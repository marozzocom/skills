# Authorship (local)

Copy to `authorship.md` (gitignored) and fill in. The skill reads it before writing.

For each text you produce, name who holds the pen: `ai`, `draft` (AI drafts, owner edits), `check` (owner writes, AI checks), `me` (owner writes), whether the owner may dictate it, and where the text lives (a repo path, a CMS, a mail client), so an audit finds every source.

| Text | Pen | Dictate? | Language | Lives in |
|---|---|---|---|---|
| Company website | draft | yes | en, fi | repo message catalog + CMS |
| Personal website | check | yes | en | |
| PR descriptions | ai | no | en | GitHub |
