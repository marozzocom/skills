# prose

Guidelines for writing prose people read, in English and Finnish: website copy, posts, email, docs, PR descriptions, commits, release notes, error messages, team chat. The skill also decides who should write a given text: AI, an AI draft the owner edits, the owner with AI checking, or the owner dictating while AI shapes it.

The guidelines come from blind calibration rounds. The owner picked between versions of the same text that differed in rhythm, imagery, punctuation, structure and register. `references/examples.md` keeps the picked and rejected versions.

## Setup

Copy `references/authorship.template.md` to `references/authorship.md` and list your own texts and who writes them. The file is gitignored.
